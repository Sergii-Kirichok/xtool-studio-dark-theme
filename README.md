# xTool Studio — тёмная тема

У xTool Studio (Windows, Electron) есть **встроенная тёмная тема** `xcs-dark`, но переключателя
в настройках нет. Этот скрипт включает её и чинит баг, из-за которого часть окон
(главная, настройки) остаётся с тёмным текстом на тёмном фоне.

Проверено на xTool Studio 1.10.15 (Windows 10).

## Как пользоваться

1. Нужен [Node.js](https://nodejs.org/) 22+ (есть встроенный `WebSocket`).
2. Закройте xTool Studio.
3. Двойной клик по `start.vbs` — программа запустится сама.
   Ярлык на рабочий стол: ПКМ по `start.vbs` → «Отправить» → «Рабочий стол».
4. В программе **Ctrl+Alt+D** — тёмная / светлая тема. Выбор сохраняется.

Если xTool Studio уже открыта обычным ярлыком, скрипт попросит её закрыть.
Путь к программе по умолчанию `%LOCALAPPDATA%\Programs\xTool Studio\xTool Studio.exe`,
другой можно задать переменной окружения `XTOOL_EXE`.

## Как это устроено

- Тема — штатная настройка программы: `localStorage["SYSTEM_SETTINGS"].theme` = `light` | `dark`
  (origin `atomm://renderer`). Записывать её напрямую бесполезно: модуль настроек держит
  свою копию и перезапишет тему при любом изменении настроек. Правильный путь — штатный
  канал `BroadcastChannel("update-system-settings-channel")` с сообщением
  `{ eventName: "update-system-settings", data: { theme } }`.
  Вид на лету переключает событие `atomm-theme-change` (`detail: theme`) в каждом окне.
- Баг программы: интерфейс собран из микрофронтендов [Wujie](https://github.com/Tencent/wujie),
  их содержимое живёт в Shadow DOM контейнера `<wujie-app>`. Тёмные цвета там объявлены
  через `:host.dark` / `:host[data-theme="dark"]`, но программа ставит атрибуты темы только на
  `<html>`, а не на контейнер. Скрипт копирует `class` (`dark`, `theme-xcs-dark`) и
  `data-theme` / `data-studio-theme` с `<html>` на каждый `<wujie-app>`.
- Доступ к окнам — через `--remote-debugging-port=9333` (Chrome DevTools Protocol).
  Файлы программы не изменяются, обновления ничего не ломают.

⚠️ Пока программа запущена так, любая программа **на этом компьютере** может управлять
xTool Studio через `127.0.0.1:9333`. Из сети порт недоступен.

## Что пробовали и почему отказались

- Инверсия всего интерфейса (`filter: invert()`) — картинки и фото с камеры уходят в негатив,
  а картинки внутри Shadow DOM CSS документа не достаёт. Костыль.
- Флаг `studioInsider` в настройках — это подписка на бета-обновления, к теме отношения не имеет.
- `themePreference` в `%APPDATA%\xTool Studio\config.json` — объявлен, но ни на что не влияет.

## Известные мелочи

Сама тёмная тема у xTool местами недоделана: например, белая плашка «Try Sound Wave Generator»
на главной, тускловатые значения в правой панели редактора.
